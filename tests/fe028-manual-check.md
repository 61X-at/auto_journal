# FE-028 — ручная приёмка на настоящем `localStorage`

Проверяйте на временном профиле браузера или в отдельном тестовом профиле: **не очищайте локальные данные своего рабочего проекта**. Для запуска — `npm ci`, `npm run dev` и откройте адрес, напечатанный Vite в терминале (обычно `/tempPage/index.html`). Сервер разработки Vite обслуживает статические файлы приложения, backend не нужен.

| № | Действие пользователя | Что должно произойти | Результат |
|---|---|---|---|
| 1 | Откройте сайт в чистом профиле | Карточка пустая, журнал и план ТО без записей | ☐ |
| 2 | «Автомобиль»: Toyota Camry, 2018, 118000 км | Карточка сохранена; после изменения пробега на 120000 — обновилась | ☐ |
| 3 | «Добавить запись»: оставьте описание/дату пустыми, затем задайте отрицательную сумму | Показаны ошибки полей; запись не создаётся | ☐ |
| 4 | Добавьте ТО «Замена масла (масло 5W-30)», дата 20.10.2026, пробег 120000, сумма 2700 | Запись появляется в журнале | ☐ |
| 5 | Добавьте «Замена тормозных колодок», тип «замена детали», дата 05.09.2026, пробег 119100, сумма 5000 | Журнал показывает октябрьскую запись раньше сентябрьской | ☐ |
| 6 | Поиск `МАСЛО` + тип «ТО», затем неизвестное слово | Сначала одна найденная запись, потом «Ничего не найдено» | ☐ |
| 7 | Измените сумму масла на 3000 | Сумма за всё время 8000 ₽; категории 3000 ₽ и 5000 ₽ | ☐ |
| 8 | Выберите период 20.10.2026–20.10.2026 | Итог 3000 ₽, обе границы включены | ☐ |
| 9 | Удалите запись о колодках с подтверждением | Останется одна запись, итог за всё время — 3000 ₽ | ☐ |
| 10 | План ТО: добавьте «Следующая замена масла» — 31.12.2026 или 119500 км | При пробеге 120000 — статус «Требует внимания», на главной видно ближайшее ТО | ☐ |
| 11 | Отметьте работу выполненной | Перешла в «Выполненные работы», исчезла из активных и с главной | ☐ |
| 12 | **Нажмите F5** и перейдите по главным разделам | Данные автомобиля, запись, расчёт и `done` восстановлены из **настоящего** `localStorage` | ☐ |
| 13 | Проверьте 360, 768 и 1200 px в DevTools | Нет горизонтальной прокрутки, основные кнопки доступны | ☐ |
