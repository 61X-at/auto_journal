# АвтоЖурнал (AutoJournal)

Учебный клиентский веб-проект для ведения истории обслуживания одного автомобиля.

## Текущий этап: лабораторная № 5

К семантической HTML-странице из ЛР № 4 добавлен отдельный CSS-файл `tempPage/styles.css` с оформлением в соответствии с прототипом ЛР № 3. Используются CSS Grid, Flexbox и адаптивные медиазапросы (1050 / 740 / 520 px). Есть стили для навигации, карточки автомобиля, ближайшего ТО, сводки расходов, журнала, формы и мобильной версии.

**Важно:** это статическая страница. Данные демонстрационные; поиск, редактирование и сохранение в localStorage будут реализованы позднее. Backend и авторизация не входят в MVP.

## Запуск

**Без установки:** откройте `tempPage/index.html` в современном браузере.

**Через Vite:**

```bash
npm install
npm run dev
```

При запуске через Vite откройте адрес, указанный в терминале (обычно `http://localhost:5173/`).

Проверка сборки:

```bash
npm run build
```

## Что проверять для ЛР № 5

1. CSS подключён в `<head>` через `<link rel="stylesheet" href="./styles.css">`.
2. Элементы оформлены с помощью понятных классов.
3. Сетка панелей построена на CSS Grid, внутреннее выравнивание — на Flexbox.
4. На широком экране навигация находится слева, на планшете — сверху, на телефоне — снизу.
5. На узких экранах формы и карточки перестраиваются в один столбец, нет горизонтального переполнения страницы.
6. Использованы семантические `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` и подписи к полям.
