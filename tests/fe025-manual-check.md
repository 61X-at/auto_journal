# FE-025 — ручная проверка клавиатуры и форм

Откройте приложение через `npm ci && npm run dev`, затем адрес Vite с `/tempPage/index.html`. По возможности используйте чистый профиль браузера или тестовые данные: приложение хранит информацию локально.

1. **Пропуск навигации.** С самого начала нажмите `Tab`. Первой должна появиться ссылка «Перейти к содержимому» с видимым фокусом. `Enter` переводит к основному содержимому. Кнопки меню и все ссылки должны быть доступны через Tab и Shift+Tab.
2. **Автомобиль (`#/car`).** С клавиатуры перейдите к кнопке сохранения, нажмите Enter при пустых полях. Должны появиться текстовые ошибки; фокус перемещается к «Марка». Исправьте поля: ошибки исчезают, значения остаются, сохранение подтверждается текстом.
3. **Новая запись (`#/journal/new`).** Перейдите к кнопке «Сохранить запись» с помощью Tab и нажмите Enter. Первым ошибочным полем будет «Тип события». Ошибка должна читаться вместе с подписью поля; в инспекторе проверьте `aria-invalid`, `aria-describedby`, `aria-errormessage`. Введите корректные данные и снова отправьте Enter. Откроется журнал с подтверждением.
4. **Журнал (`#/journal`).** Нажимая Tab, попадите в поиск, выбор типа и кнопки «Найти»/«Сбросить». Поиск и сброс должны работать по Enter. На карточке записи проверьте доступность «Изменить» и «Удалить» с клавиатуры.
5. **План ТО (`#/maintenance`).** Tab → кнопка «Добавить работу» → Enter. Появляется форма и фокус на названии. Попытайтесь сохранить только с названием: должна появиться ошибка контрольной даты и/или пробега. Укажите одну контрольную точку; Enter сохраняет работу. Отметьте работу «Выполнено» через Enter — статус виден текстом и фокус сохраняется в понятном месте.
6. **Видимый фокус.** Обратите внимание на светлые поля, кнопки, `details/summary` и тёмное меню. Фокус должен быть хорошо различим и не определяться только сменой цвета текста.
7. **Размеры.** Повторите основные действия при ширинах 360 px и 390 px; проверьте, что поля не обрезаны, а горизонтальная прокрутка отсутствует.

Автоматизированный Chromium-прогон FE-025 покрывает пропуск навигации, Enter в формах и фильтрах, фокус на первой ошибке, подписи вводов, открытие формы ТО и отметку выполненной работы. Это не заменяет тестирования настоящими скринридерами и отдельный аудит WCAG.
