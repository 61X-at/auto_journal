# FE-026 — ручная проверка адаптивности

## Подготовка

1. Убедиться, что FE-025 уже объединена с основной веткой. Выполнить `npm ci`, `npm test`, `npm run build`, затем `npm run dev`.
2. Открыть адрес Vite, указанный в терминале (обычно `http://localhost:5173/tempPage/index.html`).
3. В инструментах разработчика открыть режим устройства (Device Toolbar) и последовательно выставить **360, 768, 1200 px**.
4. Для полноты добавить автомобиль, три записи с различными типами и минимум две плановые работы. Одну работу сделать требующей внимания; одну отметить выполненной.

## Матрица проверок

| Экран | 360 px | 768 px | 1200 px |
|---|---|---|---|
| Главная `#/home` | Карточки одна под другой, нижняя навигация, фильтр периода и поиск доступны | Колонки и кнопки не пересекаются | Боковая навигация, обе верхние карточки видны |
| Автомобиль `#/car` | Данные и форма в одну колонку, поля и сохранение доступны | Форма в две колонки | Карточка и форма читаемы |
| Журнал `#/journal` | Записи в мобильных карточках, кнопки «Изменить»/«Удалить» доступны | Сетка фильтров не пересекается с записями | Даты, суммы, фильтры и кнопки читаемы |
| План ТО `#/maintenance` | Работы и кнопка «Выполнено» не обрезаны; форма на всю ширину | План и форма читаемы | Работы, статусы и форма доступны |

Дополнительно проверить `#/journal/new`, в том числе кнопки «Сохранить запись» и «Отмена».

## Стресс-сценарии

1. В «Мой авто» указать длинное название модели (например, повторить `ОченьДлинноеНазваниеМодели` несколько раз **без пробелов**). На главной и в карточке автомобиля текст переносится и остаётся видимым.
2. В журнале добавить длинное описание без пробелов. Оно полностью читается в журнале и на главной; горизонтальная прокрутка документа не возникает.
3. В план ТО добавить длинное название без пробелов, только по пробегу, и проверить перенос заголовка и доступность «Выполнено».
4. Развернуть «Расходы по категориям», открыть фильтр периода и форму ТО. Оба состояния должны укладываться в ширину.
5. Проверить длинные подписи/сообщения об ошибках и фокус Tab. Кнопки и инпуты не перекрываются.
6. После каждой проверки выполнить в Console:

```js
console.log(document.documentElement.scrollWidth, window.innerWidth);
```

**Ожидается:** первый результат не больше второго (возможна разница в 1 px из-за округлений). Проверить отсутствие горизонтального перемещения страницы жестом или тачпадом.

## Замечания

FE-026 меняет только CSS адаптивности и тесты. Хранилище и поведение форм, расчётов и планов не меняются. Chromium-проверка на контрольных ширинах выполнялась отдельно, поскольку `npm test` не запускает браузер и не измеряет CSS-геометрию.
