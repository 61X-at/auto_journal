# FE-028 — протокол сквозной приёмки «АвтоЖурнала»

**Основание:** строка FE-028 исходного backlog и раздел 11 «Acceptance Criteria и Definition of Done» файла `Mini_PRD_ТЗ_АвтоЖурнал_Тиунов_Андрей.docx`.

**Контрольный прогон:** Chromium, чистое изолированное состояние, ширины **1200 px** и **360 px**. Последовательность выполнена через реальные поля, кнопки, маршруты и JS проекта; сервер и внешние запросы не нужны. Всего **78 из 78 проверок прошли** (39 на каждой ширине). Плюс **362 из 362 Node-теста** проекта, включая 11 новых FE-028. Полный машинный протокол включён в комплект FE-028.

> **Граница проверки:** политика тестовой среды блокирует локальные URL. Браузерный сценарий запускает исходные JS-модули через `Blob` URL, подменяет `localStorage` изолированным объектом и при повторном открытии передаёт сохранённый JSON новому документу. Это проверяет работу всех экранов и восстановление состояния, **но не заменяет** тест настоящего `localStorage` и F5 на обычном локальном origin. Для этой проверки есть отдельный ручной чек-лист ниже.

## Acceptance Criteria — исходные группы и результаты

| ID | Что требует ТЗ | Проверенное основание | Результат |
|---|---|---|---|
| AC-01 | Запись со всеми полями; ошибки обязательных полей, отрицательных значений и даты; сохранение и повторное открытие; редактирование и удаление с пересчётом | В браузере: пустые дата/описание и отрицательная сумма не сохраняются; создание, редактирование, удаление и пересчёт; в Node дополнительно проверена модель/валидация. Повторное открытие — с сохранённым JSON | **PASS (модель и браузерный сценарий)**; нативный F5 — вручную |
| AC-02 | Сортировка от новых к старым; поиск без учёта регистра совместно с категорией; результат «Ничего не найдено» | Две записи с разными датами, комбинированный запрос `МАСЛО` + ТО, запрос без совпадений и сброс | **PASS** |
| AC-03 | План с датой и/или пробегом; внимание по достигнутому порогу; выполненная работа неактивна после повторного открытия | В браузере: дата + пробег, срабатывание пробега, `done`, исчезновение из активных и восстановление из сохранённого JSON; в Node дополнительно проверены дата/пробег по отдельности | **PASS (модель и браузерный сценарий)**; нативный F5 — вручную |

## Результаты и ограничения

- **PASS:** основной сквозной путь на обеих ширинах, ошибки валидации, поиск, расходы, план ТО, отсутствие непойманных JS-исключений и горизонтальной прокрутки на 360 px.
- **Не проводилось в FE-028:** настоящее `localStorage` на `http://localhost` после F5, запуск с `npm run build`, тестирование на других браузерных движках, независимое пользовательское тестирование с 2–3 участниками (это FE-029).
- **Наблюдение по поиску:** поиск FE-013 основан на подстроке. Запрос `масло` не является морфологическим поиском: он не обязан совпадать со словоформой `масла`, если в описании нет слова `масло`. В контрольной записи обе словоформы присутствуют; результат ожидаемо найден.
- Изменения FE-028 касаются **только тестов, документации и команды запуска тестов**. Основные JS-модули и интерфейс не изменены.

**Итог:** основные US-01–US-08 и AC-01–AC-03 покрыты и прошли автоматизированную проверку. Перед закрытием FE-028 на своём компьютере выполните ручной сценарий нативного хранения из `fe028-manual-check.md`.
