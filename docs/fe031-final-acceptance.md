# FE-031 — Итоговая проверка опубликованного «АвтоЖурнала»

## Основание и критерии backlog

**Задача:** FE-031 — «Опубликовать демо и выполнить финальную проверку».

- HTTPS-демо доступно без обязательного входа.
- В опубликованной версии работает добавление и поиск записи **после повторного открытия**.
- Проверены навигация, сохранение в `localStorage` и мобильная версия.

**Адрес:** https://61x-at.github.io/auto_journal/

## Запуск проверки реального демо

Приложение не должно требовать аккаунта. Тест выполняется в двух **изолированных контекстах** Chromium (1200 и 360 px); каждый контекст заводит одну искусственную запись и проверяет её сохранность через нативный `localStorage`, F5, закрытие и повторное открытие вкладки. Тестовые записи НЕ добавляются в профиль обычного пользователя и исчезают после закрытия тестового контекста.

```bash
python -m pip install "playwright>=1.50,<2"
python -m playwright install chromium
python tests/fe031-live-smoke.py \
  --url https://61x-at.github.io/auto_journal/ \
  --report fe031-live-report.json \
  --screenshots fe031-live-screenshots
```

Также можно открыть GitHub → **Actions → Verify Published AutoJournal (FE-031)**. Этот отдельный workflow запускается автоматически после успешной публикации и не мешает работающему workflow деплоя. Его можно запустить вручную (`Run workflow`). По окончании скачайте артефакт **fe031-live-smoke-report** с JSON-отчётом и скриншотами.

**Важно:** `fe031-live-report.json` — только результат реального браузерного запуска. При отсутствии интернета, недоступном домене, ошибках JS или несохранённой записи тест завершится с кодом 1 и сообщением `FAIL`; ни скрипт, ни документация не должны фиксировать вымышленный успех.

## Ограничения

У «АвтоЖурнала» нет сервера, аккаунтов или синхронизации: `localStorage` привязан к текущему домену и профилю браузера. Очистка данных сайта удаляет автомобиль, записи и план ТО. Записи с localhost автоматически не попадают на GitHub Pages. Пользовательское тестирование FE-029, согласно сообщению организатора, пройдено по целевым временам, однако фактические секунды не предоставлены и должны быть внесены в `tests/fe029-session-results.csv`.

## Решение о закрытии FE-031

Закрыть FE-031 в YouGile можно после успешного `Verify Published AutoJournal (FE-031)` или эквивалентной ручной проверки опубликованной версии. После подтверждения сохранить ссылку на HTTPS-сайт и протокол smoke-теста в карточке задачи.
