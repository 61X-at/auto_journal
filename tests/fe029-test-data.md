# FE-029 — подготовка одинакового тестового профиля

**Внимание:** следующий код **заменяет** значения `autojournal_v1_car`, `autojournal_v1_entries`, `autojournal_v1_plans` в `localStorage` **текущего сайта и текущего профиля**. Не запускайте в своём обычном браузере с реальными данными! Используйте отдельный временный профиль/окно и проверьте адрес приложения.

1. Запустите `npm ci` (один раз), затем `npm run dev`, откройте `/tempPage/index.html`.
2. В **отдельном тестовом профиле браузера** откройте DevTools → Console, вставьте код ниже и нажмите Enter.
3. Перезагрузите страницу и проверьте, что появилась Kia Rio и пять событий в журнале. Перейдите на главную, закройте DevTools и передайте управление участнику.
4. Перед следующим участником используйте **новый временный профиль** и повторите подготовку. Не оставляйте следы заданий предыдущего участника.

```js
// FE-029: исключительно для временного профиля. Перезаписывает тестовые ключи!
const studyFixture = {
  car: { brand: 'Kia', model: 'Rio', year: 2019, currentMileage: 87400 },
  entries: [
    { id: 'study-1', type: 'ремонт', date: '2026-01-10', mileage: 70500, description: 'Диагностика датчика', amount: 1100 },
    { id: 'study-2', type: 'замена детали', date: '2026-03-15', mileage: 74200, description: 'Замена воздушного фильтра', amount: 900 },
    { id: 'study-3', type: 'ТО', date: '2026-04-24', mileage: 79500, description: 'Проверка технических жидкостей', amount: 400 },
    { id: 'study-4', type: 'покупка', date: '2026-07-19', mileage: 83000, description: 'Набор щёток стеклоочистителя', amount: 1450 },
    { id: 'study-5', type: 'ремонт', date: '2026-09-02', mileage: 86600, description: 'Замена лампы фары', amount: 650 },
  ],
  plans: [],
};
localStorage.setItem('autojournal_v1_car', JSON.stringify(studyFixture.car));
localStorage.setItem('autojournal_v1_entries', JSON.stringify(studyFixture.entries));
localStorage.setItem('autojournal_v1_plans', JSON.stringify(studyFixture.plans));
location.hash = '#/home';
location.reload();
```

**Проверка тестового набора:** в журнале пять записей, нужная запись — «Замена воздушного фильтра», 15.03.2026, 900 ₽. Она старше трёх самых новых записей; на главной в блоке последних записей её не видно. Вводимое участником ТО ещё **не** должно существовать.

Никаких дополнительных функций для реальных пользователей приложение от этого файла не получает. В рабочей базе localStorage эти сведения не должны появляться.
