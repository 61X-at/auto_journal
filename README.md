# АвтоЖурнал (AutoJournal)

Веб-приложение для ведения истории обслуживания одного личного автомобиля.

## Цель

Хранить в одном месте карточку автомобиля, историю ТО/ремонтов/покупок, расходы и планы следующего ТО.

## Статус

**Лабораторная работа № 4:** подготовлены начальная структура проекта и **только семантическая HTML-структура главной страницы**. Функции создания записей, поиска, расчёта затрат и работы с localStorage пока **не реализованы**. Числа и события на макете демонстрационные.

## Стек и ограничение MVP

- HTML5, CSS3, JavaScript; Vite для локального запуска и будущей сборки.
- В следующих лабораторных: localStorage для данных одной машины.
- Backend, регистрация, удалённая база, интеграции и push-уведомления не планируются для MVP.

## Запуск начального HTML-макета

Вариант без установки: откройте файл `tempPage/index.html` в браузере.

Вариант через Vite (нужны Node.js и npm):

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173/`).

Проверка будущей статической сборки:

```bash
npm run build
```

## Основные требования (по Mini PRD / ТЗ)

- FR-01: карточка одного автомобиля;
- FR-02: добавление, изменение, удаление записей ТО и ремонта;
- FR-03: поиск и фильтры истории;
- FR-04: суммы расходов по категориям и периоду;
